# Zip Zap Type

A bold black & white typing speed game by Suvini Khurana.

## Run it
Open `index.html` in any browser. No install, no build step.

## Edit the text
Open `script.js`. Every word on the page (title, labels, tips, ranks, share message, round lengths, passage words) lives in the `T` block at the top.

## Features
- 15 / 30 / 60 second rounds with live WPM
- Per-mode high score, saved in your browser
- Combo streak counter with a pop every 25 correct keys
- Fun rank titles based on your speed
- Last 10 rounds mini chart
- Confetti on a new high score
- Share button (share sheet or copy to clipboard)
- Light / dark toggle, Esc to restart, scroll animations
